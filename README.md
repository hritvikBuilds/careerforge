# CareerForge AI 🚀

> **Calm, Truth-Anchored Resume Enhancer & Candidate Career Accelerator**  
> Guaranteed ATS score >85% • Zero AI bot filtration footprint • PDF & Word (DOCX) resume parser • End-to-end candidate suite.

---

## ✨ Features

1. **📄 Client-Side Resume Extraction (PDF & Word DOCX):**
   - 100% private in-browser document parsing using Mozilla `pdfjs-dist` and `mammoth`.
   - Supports `.pdf`, `.docx`, `.doc`, and `.txt` files with zero server transmission.

2. **🛡️ Guaranteed ATS Score >85% (Truth-Anchored):**
   - Zero fabrication guarantee: Never invents fake titles, companies, or degrees.
   - Reframes real experience into Google's standard XYZ impact formula.
   - Contextually aligns missing JD keywords with actual candidate background.

3. **🤖 Anti-AI Filtration & Footprint Removal:**
   - Detects and scrubs typical AI cliches (*"spearheaded"*, *"delved"*, *"tapestry"*, *"orchestrated"*, *"pivotal"*).
   - Replaces them with natural, punchy human engineering verbs (*"built"*, *"shipped"*, *"led"*, *"analyzed"*).
   - Real-time Human Voice confidence score.

4. **💼 End-to-End Candidate Journey Suite:**
   - **Phase 1: Discovery & Fit:** Real-time skill gap breakdown and direct ATS Boolean search query generator (`site:greenhouse.io`, `site:lever.co`).
   - **Phase 2: Application Optimization:** Side-by-side / responsive resume editor, human-tone cover letter generator, and recruiter-optimized LinkedIn headline & DM pitch.
   - **Phase 3: Interview Mastery:** Targeted interview question predictor, 4-part STAR story builder, and salary negotiation counter-offer playbooks.
   - **Phase 4: Pipeline Management:** LocalStorage-backed Kanban application tracker and post-interview thank you email composer.

5. **🌿 Calming Pastel Design & Full Mobile Responsiveness:**
   - Soothing, anxiety-reducing pastel theme (warm stone, soft mint, gentle sky).
   - 100% mobile responsive layout with touch-swipeable Kanban boards and segmented editor views.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4
- **Parsing:** `pdfjs-dist` (PDF) + `mammoth` (Word DOCX)
- **Icons:** `lucide-react`
- **Celebrations:** `canvas-confetti`

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/hritvikBuilds/careerforge.git

# Navigate into the project
cd careerforge

# Install dependencies
npm install

# Start the development server
npm run dev
```

Build for production:
```bash
npm run build
```
